# LEGS project page

Static site for **LEGS: Fine-Tuning Teleop-Free VLAs for Humanoid Loco-manipulation in an Embodied Gaussian Splatting World**.

Built on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) (Nerfies-derived, Bulma-based).

## Preview locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Hosted at

`https://legsvla.github.io`
